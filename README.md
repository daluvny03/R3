# ERTIGA POS

ERTIGA POS adalah sistem kasir berbasis web yang dirancang untuk membantu UMKM dalam mengelola transaksi penjualan, stok produk, dan laporan keuangan secara terintegrasi.

## 🚀 Fitur Utama

### 🔐 Autentikasi
- Login pengguna
- Registrasi
- Lupa password

### 🧾 Kasir
- Dashboard kasir
- Tampil data produk
- Pencarian produk berdasarkan kategori
- Tambah transaksi penjualan
- Pilih metode pembayaran
- Cetak struk

### 📊 Admin
- Dashboard admin (stok menipis, total produk, total transaksi bulanan)
- Kelola produk (tambah, tampil, edit, hapus)
- Kelola kategori (tambah, tampil, edit, hapus)
- Kelola stok (tampil dan update stok)
- Kelola transaksi (tampil dan hapus)

### 📈 Owner
- Dashboard owner (ringkasan penjualan, laba, pengeluaran, grafik)
- Kelola laporan keuangan:
  - Laporan penjualan
  - Laporan laba rugi
  - Laporan neraca
  - Data pengeluaran
  - Export PDF

### 🤖 Analisis AI
- Prediksi penjualan
- Rekomendasi stok
- Deteksi anomali
- Customer insight
- Analisis tren

---

## 🛠️ Teknologi yang Digunakan

- **Backend**: Laravel 10 (PHP)
- **Frontend**: Blade, Tailwind CSS, Alpine.js
- **Database**: MySQL
- **Library**:
  - DomPDF (export PDF)
  - Laravel Excel
  - Chart.js
- **Tools**:
  - Visual Studio Code
  - Git
